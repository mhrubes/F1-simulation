# F1 Simulation

Jednoduchá webová simulace závodu Formule 1 v prohlížeči. Vyberete okruh, nastavíte závod a sledujete průběh na trati včetně výsledků. Aplikace běží na [Next.js](https://nextjs.org) (App Router), stav závodu je v [Zustand](https://github.com/pmndrs/zustand) a UI používá Tailwind CSS a komponenty z Radix UI.

## O projektu

Jde o experimentální / edukační projekt: fyzika závodu je zjednodušená, důraz je na plynulé UI, vizualizaci okruhu a hratelnost v jednom okně. Kód a texty vznikaly s pomocí nástrojů umělé inteligence (generování, refaktoring, překlady) — výsledné chování a odpovědnost za nasazení vždy patří autorovi repozitáře.

## Spuštění

```bash
npm install
npm run dev
```

Aplikace poběží na [http://localhost:3000](http://localhost:3000).

Další skripty: `npm run build` (produkční build), `npm run start` (spuštění buildu), `npm run lint` (ESLint).
